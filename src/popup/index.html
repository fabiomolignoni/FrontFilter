Block modes

HOME blocks only the subreddit front page and sort views, such as hot, top, new, and rising.

ALL blocks every page under that subreddit and hides its posts from Home and Popular.

You can use * as a wildcard to filter multiple subreddits, for example *news* (filters subreddits containing "news"), news* (filters subreddits starting with "news"), or *news (filters subreddits ending with "news").

Allowed subreddits

These exact subreddits override “All subreddit front pages” and blocked subreddit rules. Wildcards are not supported.

Post keywords

Hide posts when their title or text preview contains one of these keywords. Matching is case-insensitive.

Appearance

System follows your browser or device appearance.

Configuration backup

Download your controls and filter rules as a JSON file.

Settings included in the file replace their current values.
